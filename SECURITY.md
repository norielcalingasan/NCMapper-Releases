# Security reporting

The current download is an unsigned pilot. Supported security fixes target the latest pilot; no production support or response-time guarantee is offered.

Use [Report a vulnerability](https://github.com/norielcalingasan/NCMapper-Releases/security/advisories/new) for a private report to the maintainers. Include the release tag/hash, affected feature, steps using synthetic records and the observed impact. Do not publish exploit details containing resident information in public issues.

Never include passwords, session/invitation tokens, house photos, precise private coordinates, signing material or database backups. If your report involves a separately hosted community server, contact that server's coordinator privately as well.
